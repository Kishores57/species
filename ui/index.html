⚙️ How This CNN Species Detection Works (Deep Learning Lab Pipeline)
Step 1 • Preprocessing
Input Transformation
Resized to 224×224, center cropped, and normalized using ImageNet channel mean & standard deviation.
Step 2 • Feature Learning
EfficientNet-B0 Backbone
16 MBConv blocks with Squeeze-and-Excitation attention learn leaf textures, venation, and margin geometry.
Step 3 • Representation
Global Avg Pooling (GAP)
Reduces 7×7 feature maps to a 1280-dimensional feature embedding vector with 20% dropout regularizer.
Step 4 • Auto-Labelling
Softmax Classification
Linear projection maps 1280 features to 7 species logits; softmax calculates confidence distribution for automatic labeling.
